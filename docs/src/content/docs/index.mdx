## Запуск за 60 секунд

```bash
git clone https://github.com/Saka1r/Mai_catgirl && cd Mai_catgirl
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить API_ID / API_HASH / CREATOR_USER_ID
python main.py
```
